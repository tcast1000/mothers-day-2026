# Photos

Drop your photos here. By default the page expects:

- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`

Or point to whatever filenames you want by editing `src` paths in `content.js`.

JPEG, PNG, and WebP all work. Square or near-square crops look best in the polaroid frames.

These files are gitignored — they will never be tracked by git.
